## 证据标记

| 标记 | 含义 |
|---|---|
| `[P]` | 标准、同行评审论文、官方文档或作者发布的实现 |
| `[A]` | 写明假设和定义域的代数或符号推导 |
| `[N]` | 写明输入、精度、算法和 observable 的数值复算 |
| `[X]` | 尚待 Gravlume 原型验证的假设，不是已实现能力 |

不同证据不能互相替代：公式对齐不证明离散收敛；CPU 与 GPU 输出相同不证明两者都正确；视觉 golden 不证明 branch、频率比或 optical depth 正确；能加载资产不证明允许再分发。

## 文档维护规则

- 版本事实以 `Cargo.toml`/`Cargo.lock` 为准；平台文档只记录当前实施起点和升级门槛。
- 公式必须注明坐标顺序、度规符号、单位、光子时间定向和适用域。
- 性能数字必须附 profile、target、adapter、driver、extent、场景和统计量。
- 新外部方法先写“可吸收的职责”和“不能外推的边界”，再决定是否实现。
- 每项规范性结论只在一个主题文档维护。

# UI font asset

`NotoSansSC-Regular.otf` is the Simplified Chinese subset of Noto Sans CJK 2.004,
downloaded from the official [`notofonts/noto-cjk`](https://github.com/notofonts/noto-cjk/tree/main/Sans/SubsetOTF/SC)
repository. It is installed as egui's lowest-priority proportional and monospace fallback so the
default Latin faces stay unchanged while CJK text, arrows, punctuation, and mathematical labels do
not become missing-glyph boxes.
